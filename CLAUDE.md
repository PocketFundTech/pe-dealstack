# CLAUDE.md

## Reminders

- ~~AI classifier needs a current-date injection~~ — **fixed 2026-09-28 (PR #144).** `aiExtractor.ts` already injected the date; the gap was the now-live Claude extraction engine (`extraction/extractionSchema.ts`'s `EXTRACTION_SYSTEM_PROMPT`/`EXCEL_CONTAINER_INSTRUCTION`, used by `extraction/claudeEngine.ts`), which were static constants. Both are now builder functions taking `getTodayIso()` at call time. Verify any new extraction/classification prompt does the same — `grep -rn getTodayIso apps/api/src/services` to see every call site that already does.
- **New Claude call sites should use prompt caching when the prefix repeats.** Confirmed via the `UsageEvent` ledger (2026-09-28): extraction is the dominant cost driver, and a call site with no `cache_control` was quietly re-billing the full system prompt + document on every repair pass and container→text fallback. `claudeFinancialClassifier.ts`, `financialCrossVerify.ts`, `dealChatAgent/index.ts` and (as of PR `perf/extraction-prompt-caching`) `extraction/claudeEngine.ts` all mark their stable prefix `cache_control: { type: 'ephemeral' }`. When adding a new Claude call that resends the same system prompt or document across multiple calls in one run, do the same — it changes nothing about the request/response, only the bill.
- **AI runs on a user's click only.** Work nobody clicked for (cron, webhook, scheduled sync, a second AI step chained after the clicked one, generate-on-page-load) must check `isBackgroundAiEnabled()` / `canRunAiNow()` from `apps/api/src/services/usage/aiOnDemand.ts` and skip its AI step when they return false (`AI_BACKGROUND_JOBS` is off by default). A page should read cached AI results on load and offer a button to generate.
- **Start from [`CONTEXT.md`](CONTEXT.md)** — current state, open PRs, what's blocked and what's next. Update it (and `PROGRESS.md`) at the end of a work session.
- **When AI features fail in production, check credit first:** `vercel logs --environment production --since 1h --query "credit balance"`. Anthropic and OpenAI both ran out of credit on 2026-09-28 and again 2026-10-01; failures then look like code bugs (422 on PDF upload, 503 on insights, timeouts) but aren't.
- **`apps/api/scripts/` is gitignored** by the repo-wide `scripts/` rule — `git add -f` new scripts or they never reach the repo (the #164 backfill was lost this way).
- **Stacked PRs: merge bottom-up and retarget each to `main` before merging.** Merging a child after its base already merged lands it on the dead base branch (#167/#168 had to be re-opened as #169). CI (`.github/workflows/pr.yml`) only runs on PRs into `main`.
